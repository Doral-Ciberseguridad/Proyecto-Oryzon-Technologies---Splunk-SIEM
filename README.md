# Proyecto-Oryzon-Technologies---Splunk-SIEM
He desarrollado un proyecto de Splunk SIEM para Oryzon, una empresa científica ficticia que me contrata para supervisar y monitorizar su entorno tecnológico. Integro agentes Windows, analisis de eventos, MITRE ATT&amp;CK, correlaciones, alertas, automatización con Python, vigilo la telemetría, reduzco falsos positivos y valido y documento cada fase.
